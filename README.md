# Stillwater Wedding Invitation

A private, mobile-first wedding invitation workspace for one wedding. It combines a clear guest dashboard, exact guest-linked invitation URLs, WhatsApp handoff tracking, configurable event content, public media, digital gift details, and moderated guest wishes.

## Features

- Email and password protected admin dashboard.
- Responsive guest management for phones and laptops.
- Unique, server-generated invitation slug for every registered guest.
- Exact MongoDB guest lookup before any invitation payload is returned.
- Prefilled WhatsApp messages and sending timestamps.
- Two configurable events with dates, times, addresses, and Google Maps links.
- Couple photography, gallery, backsound, and live invitation preview.
- Countdown with Indonesian time zone support.
- Digital gift accounts with copy controls.
- One moderated wish per registered guest.
- Mobile-first Stillwater Letters invitation design.

## Stack

- React 19 and Vite
- React Router
- Express 5
- MongoDB Atlas

## Local Setup

Install dependencies:

```bash
npm install
```

Create a local environment file from `.env.example` and fill in the required values. Do not commit `.env` or real credentials.

Generate an admin password hash:

```bash
npm run hash-password -- "your-password-at-least-10-characters"
```

Place the command output in `ADMIN_PASSWORD_HASH`.

Run the API and frontend in separate terminals:

```bash
npm run dev:api
```

```bash
npm run dev
```

The Vite development server proxies `/api` to `http://localhost:3000`.

## Environment Variables

| Variable | Purpose |
|---|---|
| `MONGODB_URI` | MongoDB Atlas connection string |
| `MONGODB_DB` | Database name, defaults to `wedding_invitation` |
| `ADMIN_EMAIL` | The only accepted admin email |
| `ADMIN_PASSWORD_HASH` | `scrypt` hash generated by the included script |
| `SESSION_SECRET` | At least 32 random characters used to sign sessions |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob read-write token |
| `APP_URL` | Exact public origin, without a trailing slash |

For local development, `APP_URL` is normally `http://localhost:5173`.

## MongoDB Atlas

1. Create a free cluster and database user.
2. Use a long, unique database password.
3. Allow network access from Vercel. Atlas usually requires `0.0.0.0/0` because Vercel Hobby functions do not have fixed outbound IPs.
4. Keep the credentials restricted to this database and only expose the connection string through Vercel environment variables.

The application creates the required unique slug and wish indexes when a warm database connection is initialized.

## Vercel Blob

Enable Blob for the Vercel project. Vercel creates `BLOB_READ_WRITE_TOKEN` automatically for linked deployments. Client uploads request a short-lived token through the authenticated Express endpoint. Accepted media:

- JPG, PNG, or WebP images.
- MP3 or M4A audio.
- Maximum 8 MB per image in the dashboard.
- Maximum 15 MB per audio file.
- SVG is rejected.

Compress music and photography before upload to conserve free-tier storage and bandwidth.

## Deploy to Vercel

1. Import this repository into Vercel.
2. Keep the detected Vite build command and `dist` output directory.
3. Add all environment variables for Preview and Production.
4. Enable Vercel Blob.
5. Deploy and verify `/api/health`.
6. Log in, create one test guest, configure the invitation, and open its generated link.
7. Confirm a random or edited slug returns `Undangan tidak ditemukan`.
8. Test one WhatsApp handoff from a real phone.

## WhatsApp Tracking

`Sudah dikirim` means the dashboard opened WhatsApp with the guest number and prepared message, then saved `sentAt`. Regular `wa.me` links cannot confirm that WhatsApp sent, delivered, or read the message. Admins can reset the status if they cancel the handoff.

## Invitation Slug Security

- Slugs can only be generated by authenticated server actions.
- Each slug includes a random suffix and has a unique database index.
- Public invitation content is returned only after an exact registered-guest lookup.
- Unknown, manually edited, deleted, or replaced slugs receive the same generic 404 response.
- Guest phone numbers and relationship data are never included in public invitation payloads.

## Troubleshooting

### Login always fails

Confirm `ADMIN_EMAIL` matches exactly and regenerate `ADMIN_PASSWORD_HASH`. Restart the local API after changing environment variables.

### API reports `MONGODB_URI belum dikonfigurasi`

Load the local `.env` through your shell or deployment environment. Node does not read `.env` automatically in this project.

### Upload fails

Confirm Blob is enabled, the token is available to the API, the admin session is valid, and `APP_URL` exactly matches the browser origin.

### Invitation is not found

The URL must use the current slug shown in the registered guest record. Regenerating a slug invalidates the previous URL immediately.

### Music does not start automatically

Browsers require a user gesture. Music starts after the guest presses `Buka undangan`; it always remains manually controllable.
