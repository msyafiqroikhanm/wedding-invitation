# Public invitation — Album Biru

- **Mode:** Experience, with direct access to ceremony details and personal wishes.
- **Intent:** A registered guest opens a personal photographic keepsake, meets the couple, finds the ceremonies, and leaves a moderated wish. Preserve exact-guest access and conditional content.
- **Committed concept:** Archival photo album, direction 4, seed `369ba90e`; the durable contract is in `index.html`. Visual tokens and responsive rules belong to root `DESIGN.md`.
- **First viewport:** Phone names above a mounted photograph and named dedication/opening action; desktop print beside names and dedication. The cover is a dark protective album front, not text over a full-bleed photograph.
- **Sequence:** Cover → opening letter → staggered couple portraits → countdown → ceremonies → optional full-width photo interlude → optional horizontal album gallery → optional gift disclosure → wishes → closing names.

- **Authority:** Capture the implemented guest output, not the admin phone mockup (still legacy mauve/Playfair). Shared CSS and `index.html` are evidence, not additional globally mapped surface targets.
